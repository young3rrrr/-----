# Лабораторні роботи з дисципліни МАВПЗ

## Проєкт: **openCRM**

### Огляд предметної області (Domain Overview)
- Веб-платформа для управління відносинами з клієнтами та автоматизації воронки продажів для компаній сегмента B2B/B2C.
        
### Межі системи (System Scope)

**Ліди та первинні звернення (Leads)**:
* Фіксація вхідних контактів потенційних клієнтів (ім'я, email, статус).
* Призначення відповідального менеджера для супроводу ліда.
* Кваліфікація ліда та його строга конвертація в постійного клієнта (1:1).

**Клієнтська база (Clients)**:
* Централізований облік контрагентів і компаній.
* Збереження контактних персон, номерів телефонів та унікальних email.
* Повна історія відкритих та успішно закритих комерційних угод.

**Воронка продажів та каталог (Deals & Products)**:
* Супровід життєвого циклу угод за стадіями (`new`, `negotiation`, `contract`, `won`, `lost`).
* Формування специфікації угоди через позиції замовлення (`DealItem`) із вибором товарів із каталогу.
* Фіксація транзакційної ціни продажу (`actual_price`) та оперативний підрахунок підсумкової суми угоди (`total_amount`).

**Комунікації та менеджмент (Activities)**:
* Планування завдань і активностей менеджерів (`call`, `meeting`, `email`).
* Можливість постановки автономних внутрішніх завдань (`internal_task`) без обов'язкової прив'язки до клієнта чи угоди.
